# Week # 실습 기록

## 목표
AI에게 코드 설명을 요청하는 방법을 익히고, 방향키로 도형을 움직이는 프로그램을 만들어본다

## AI 대화 기록

**Q1: 물체를 움직일 수 있도록 할 때 특정 키를 누를 때마다 움직이게 하려면 어떻게 해야 해?

- AI 답변: keys = pygame.key.getpressed() 문구를 통해 키를 누를 시 움직이도록 할 수 있고, [pygame.K ]와 -=, += 등의 기호와 문구를 이용하여 키 지정 및 움직일 방향을 정할 수 있다.
- 적용 결과: 원하는 이동방식을 적용 성공

**Q2: 각각의 도형들이 충돌할 시 색이 바뀌도록 하기 위해서는 어떻게 해야 해?

- AI 답변: is_colliding = distance < circle_radius + trisize 이 코드를 이용하여 도형간의 충돌이 생기도록 한 뒤 tuple(random.randint(0, 255) for  in range(3)) 이 코드를 이용하여 색이 바뀌도록 한다.
- 시행착오: 색이 무작위로 바뀌는 코드를 추가하였더니 기존에 없던 문제인 충돌한 도형이 서로를 통과하는 문제가 발생하여 AI에게 이를 해결하기 위한 코드 부탁하여 해결하였다.
- 적용 결과: 정상적으로 충돌 시 색이 바뀌도록 설정 성공

**Q3: 자유롭게 움직이는 도형을 만드려면 어떻게 해야 해?

- AI 답변: 자유롭게 이동시킬 도형의 이동 속도와 방향을 설정한 뒤 벽에 닿을 시 방향이 반전되도록 설정한다.
- 적용 결과: 자유롭게 이동하는 도형 생성 성공

## 배운 점
- AI를 이용하여 코드를 만드는 방법 및 게임에 직접 적용시켜보며 생기는 문제를 해결해 나가는 방법에 대해서 실습을 통해 배울 수 있었다.
