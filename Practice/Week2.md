# Week 2 실습 기록

## 목표
Git 및 VSCode, GitHub 사용법 익히기

## AI 대화 기록
**Q1: VSCode에 Portable Git을 적용시키려면 어떻게 해야 하는가?**
- AI 답변: (D:\\PortableGit\\cmd\\git.exe)같은 파일의 위치를 찾은 후 "git.path": (링크)에 붙여 넣어라
- 적용 결과: AI가 말한 순서를 따라가며 적용 완료

**Q2: GitHub에 Push할 때 Token을 입력하면 보이지 않는 것이 정상인가?**
- AI 답변: 보안 등의 이유로 Git에 Token을 입력할 경우 보이지 않는 경우가 존재함
- 적용 결과: 정상적으로 넘어감

**Q3: branch를 master로 하였더니 정상적으로 push를 할 수 없었다.**
- AI 답변: branch가 master일 경우 GitHub의 기본 브랜치와 다른 경우가 있어 push할 수 없는 경우가 있다.
- 적용 결과: AI의 설명에 따라 branch를 main으로 바꾸는 것으로 정상적으로 push함

## 어려웠던 점
