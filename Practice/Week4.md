# 4주차 실습 정리

## 오늘 한 것
- 원형 / AABB / OBB Bounding Box 시각화
- 새 방식의 충돌 판정 차이 관찰

## 관찰 내용

### 원형 VS AABB
- 원형의 경우 말 그대로 원형의 충돌 범위를 가지고 있어 총알이나 캐릭터의 간단한 범위 등 거리를 계산해야 할 때 사용된다.
- AABB의 경우 축이 정렬된 사각형 모양의 충돌 범위를 가지고 있어 UI 버튼이나 플랫폼 게임의 벽이나 바닥 등에 사용된다.

### AABB VS OBB
- OBB는 AABB에서 회전까지 반영한 사각형 형태의 충돌 범위로 회전하는 오브젝트가 쓰이는 전반적인 물리 기반 게임에서 사용된다.

## AI와의 대화에서 배운 것

**Q1: AABB와 OBB의 장단점은 어떤 것들이 있는가**
- AI 답변: AABB의 경우 연산이 거의 없어 매우 빠르고 구현이 쉬우나 정확도가 떨어지는 단점이 있다. OBB의 경우 정확도가 높고 회전되는 물체에 적합하지만, 계산이 복잡하고 AABB보다 느리다는 단점이 있다.
- 결과 : AABB와 OBB의 장단점에 대해 생각하며 실습에 임할 수 있었다.

**Q2: 이러한 충돌 범위를 실제 게임에서는 어떻게 사용하는가**
- AI 답변: 실제 게임에서는 원형이나 AABB를 통해 1차로 간단한 충돌 등을 확인하고 OBB를 통해 2차 및 최종 정확 판정을 한다.

**Q3: 여러 장르의 게임에서 이러한 충돌 요소는 어떻게 나누어 사용하는가**
- AI 답변: FPS 장르의 경우 총알 같이 범위를 나타내야 하는 경우 원형을, 플레이어는 AABB를 사용하며, 무기 등은 OBB를 사용한다. 플랫폼 장르의 경우에는 플레이어나 바닥, 벽 등 대부분의 물체에 AABB를 사용한다. 액션 장르의 경우 플레이어는 AABB를 적들은 원형을 사용하며, 무기 또는 회전하는 물체에는 OBB를 사용한다.
- 결과 : 이 답변을 통해 내가 만들 게임에 어떤 충돌 방식을 사용할 지 생각할 수 있었다.

## 내 게임에 적용한다면
- 내 게임에 적용한다면 원형과 AABB 방식을 주로 사용할 것 같다. 그 이유는 회전이라는 요소를 많이 넣은 게임을 만들기보다는 물체의 범위나 UI 등 원형과 AABB를 더 많이 사용하는 게임을 만들 생각이기 때문이다.
